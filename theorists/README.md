# Theorist portraits

One photo per profile in the Translation Theories guide. Save each file in this
folder with **exactly** the filename below (a square-ish photo crops best).
Until a file exists the profile shows an empty frame — never initials, never a
stand-in, never a generated face.

Only use images you have the right to publish — for example, Wikimedia Commons
images under a free licence, or photos the person or their university has
released. Note the source and licence beside each one.
